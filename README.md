# ✨GlowGuide-Ai
Personalized skincare recommendation engine using ML + Groq LLM to generate explainable, data-driven skincare routines through an interactive Gradio app.

---

## 📌 Overview

GlowGuide AI provides customized skincare recommendations based on user inputs such as:
- Age
- Skin Type
- Skin Concern
- Budget
- Season
- Water Intake
- Sleep Duration
- Sunscreen Usage
- Makeup Usage
- Sensitive Skin
- Current Skincare Routine

The application predicts a suitable skincare routine using a Machine Learning model and then generates a detailed, personalized skincare report using the Groq LLM through an interactive Gradio interface.

---

## 🚀 Features

- Personalized skincare recommendations
- Machine Learning-based prediction
- AI-generated skincare routine using Groq LLM
- Interactive Gradio interface
- User-friendly input form
